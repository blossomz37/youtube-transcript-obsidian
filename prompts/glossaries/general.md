# General caption glossary

Common auto-caption errors in videos about AI tools and author software.
Wherever the transcript shows a variant in the left column, read the term in
the right column.

| Captions may show | Correct term |
|---|---|
| Chat GPT, chat GPT, chat gpt | ChatGPT |
| GPT6, GPT 6 | GPT-6 |
| codeex, co-decks, codecs (when about OpenAI's coding agent) | Codex |
| cloud code, clod code | Claude Code |
| MPC server, NPC server | MCP server (Model Context Protocol) |
| AISMs, AI isms | AI-isms (predictable AI prose tics) |
| pros (when about writing) | prose |
| rag (when about AI context) | RAG (retrieval-augmented generation) |
| guey, gooey (when about interfaces) | GUI (graphical user interface) |
| next js | Next.js |
| Attacus | Atticus (book formatting software) |
| clipton strengths | CliftonStrengths |
| Mary Shelly | Mary Shelley |
| HG Wells | H.G. Wells |
| Jane Austin | Jane Austen |
| 20 books, 20 books Vegas | 20Books Vegas (now called Author Nation) |

Chat usernames and slang are usually not caption errors. Leave them as shown
unless a listed term clearly applies.
